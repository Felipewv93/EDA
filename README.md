# Análise Exploratória de Dados

Repositório de projetos desenvolvidos durante a faculdade na disciplina de Análise Exploratória de Dados (EDA).

A pasta será atualizada gradualmente conforme novos conteúdos, datasets e atividades forem desenvolvidos.

## Objetivo

Reunir estudos práticos de análise de dados utilizando Python, com foco em:

- carregamento e organização de datasets;
- limpeza e preparação dos dados;
- estatística descritiva;
- análise de correlação e outliers;
- criação de gráficos e visualizações;
- interpretação dos resultados e elaboração de conclusões.

## Tecnologias e bibliotecas

Os projetos utilizam, conforme a necessidade de cada atividade:

- Python;
- Pandas;
- NumPy;
- Matplotlib;
- Seaborn;
- Jupyter Notebook ou Google Colab, quando aplicável.

## Observações

Este é um README provisório e de visão geral. Cada projeto possuirá sua própria documentação com detalhes sobre o dataset, metodologia, resultados, gráficos e conclusões.

Novos projetos e exercícios serão adicionados a este índice conforme o desenvolvimento das atividades acadêmicas.
